HOW TO APPLY THIS UPDATE
========================

This ZIP is an overlay for your existing riscv-processor-verilog repository.
It contains the updated source and documentation files at their normal project
paths. It deliberately does not include or overwrite your .git directory,
Makefile, .gitignore, or local build directory.

1. Extract this ZIP into the root of your existing local repository folder:
     ~/Downloads/riscv_intermediate_project
   Choose to overwrite/replace files when prompted.

2. Open a terminal in that project folder and run:
     make clean
     make test

3. Confirm the final output says:
     PASS: all nine RISC-V instruction checks succeeded.

4. If the simulation passes, review the changed files and commit/push:
     git status
     git add src/alu.v src/control_unit.v src/riscv_cpu.v \
       tb/tb_riscv_cpu.v program.asm program.hex riscv_design.v \
       README.md SUBMISSION_CHECKLIST.md circuit_diagram.dot \
       circuit_diagram.png circuit_diagram.svg
     git commit -m "Add AND OR XOR instruction support"
     git push

The testbench writes build/wave.vcd. It is not included in this ZIP because
it must be generated by your own simulation run. Open it with:
     gtkwave build/wave.vcd

The processor remains a selected nine-instruction subset of RV32I, not a
complete RV32I implementation.
